# Synthetic shapes: real upstream runtime control

This is an original deterministic 512×512 grayscale TIFF pair generated by
[`make_control.py`](../../scripts/make_control.py), not lab tissue or third-party
image data. A declared 1 µm/pixel calibration exists only to exercise units.
The generator creates files privately when validation runs; no upstream image,
source code or binary is redistributed. The shape pattern is not a biological
reference and no accuracy claim or target fiber count is asserted.

After the reviewed release is built, run in its allocated CPU environment:

```bash
wagers-myotally validate-one --evidence-dir /absolute/new-control-evidence
```

Expected contract: one actual upstream field run, a visible missing-laminin
failure before creating a bad run, a valid retry, original/manifest/sentinel hashes
unchanged, real nonempty outputs, and a mechanical synthetic review/animal export.
The commands/settings and observed status are saved in `validation.json`.
No GUI or human biological review is claimed by this control.

The actual 2026-10-19 **Mac ARM64 source-CLI** run produced 61 fiber rows in both
first and retry runs. That observed number is not a cross-platform golden count
or an accuracy score. [Observed evidence](observed-mac.json) records versions,
settings, timestamps, hashes and scope. [The small exported CSVs](observed-mac-exports/fibers.csv)
and [animal/muscle summary](observed-mac-exports/animal-summary.csv) are actual runtime
outputs on these synthetic shapes, normalized to LF for portable sharing.
The summary includes `muscle_id` and groups by study/animal/muscle; its dystrophin
count/fraction is blank because no positivity was scored. The refreshed run was
executed after revision-1 fixes at checkpoint
`94c6647afa426070090a10c2c845fa860f354bc2`. The evidence includes executable/test
SHA256s and UTC windows; nine focused tests passed before the actual control.
Its CNF/CSA values have no biological interpretation.

Linux resolved builds, Linux runtime evidence and real lab-image acceptance remain
open. Differences on another platform must be investigated and recorded rather
than hidden by changing an expected count. For a real lawful field, use the
one-row manifest mode in the [CLI guide](../../docs/cli.md); human review remains
required and is never automatically filled for user images.
